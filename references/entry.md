# 入口参数与解析规则

## 参数契约

| 参数 | 必填 | 取值 |
|---|---|---|
| `target` | 是 | BV号 / B站URL / 本地视频路径（位置参数） |
| `--goal` | 是 | `deep_mastery` \| `exam_cram` |
| `--textbook` | 否 | 本地 PDF/EPUB |
| `--slides` | 否 | 本地 PDF/PPTX/DOCX |
| `--exams` | 否 | 本地目录或文件 |
| `--emphasis` | 否 | `subject` \| `course` \| `textbook`，不填则自动推断 |
| `--course` | 否 | kebab-case 课程 id，不填则从标题生成 |
| `--pages` | 否 | 分P 范围，如 `2-19` |
| `--lectures` | 否 | 讲次范围，如 `1-3,5` |
| `--all` | 否 | 全部有效分P（自动过滤介绍页） |
| `--include-intro` | 否 | 强制包含被判定为介绍页的分P |
| `--sections` | 否 | 只跑片段，如 `00:00:00-00:05:00` |
| `--resume` | 否 | 从上次中断处继续 |

`--goal` 无默认值，必须显式给出。

## 中文到参数映射

| 用户表述 | 映射 |
|---|---|
| 蒸馏课程 / 蒸馏这门课 / 蒸馏这个网课 | 触发 |
| 深度掌握 / 好好学 / 精通 / 吃透 / 学明白 | `--goal deep_mastery` |
| 考试突击 / 备考 / 速成 / 不挂科 / 应付考试 | `--goal exam_cram` |
| 全部 / 所有章节 / 全部P / 整门课 | `--all` |
| 只要第X、Y讲 / 只学X-Y | `--lectures X,Y` |
| 教材 / 课本 / 书 + 路径 | `--textbook` |
| 课件 / PPT / 幻灯片 + 路径 | `--slides` |
| 真题 / 往年题 / 题库 + 路径 | `--exams` |
| 给了 BV 号或 bilibili 链接 | `target` = B站 |
| 给了 .mp4/.mkv/.flv 路径 | `target` = 本地 |

## emphasis 自动推断

| goal | 素材 | 推断值 |
|---|---|---|
| deep_mastery | 有教材 | `textbook` |
| deep_mastery | 只有网课 | `course` |
| deep_mastery | 只有课件 | `subject` |
| exam_cram | 任意 | `course` |

用户显式给出 `--emphasis` 则覆盖推断。

## emphasis 行为差异

| 值 | 画面权重 | 字幕权重 | 课件权重 | 产物倾向 |
|---|---|---|---|---|
| `subject` | 中（只取公式/图表） | 中 | 高 | 学科体系完整，跨讲次串联 |
| `course` | 高（板书/口述细节全留） | 高 | 中 | 忠实还原这门课怎么讲 |
| `textbook` | 低（只补教材没有的） | 低 | 高 | 教材为主干，视频作注解 |

## 缺参数的反问

```
缺 target  → "要蒸馏哪门课？给 BV 号/链接，或本地视频路径。"
缺 goal    → "目标是深度掌握，还是考试突击？"
两者都缺   → 一次问清
```

非视频素材缺失不追问。

## 介绍页过滤

默认 `--all` 时自动过滤，满足任一条件即排除：

1. 时长 < 180 秒
2. 标题含：简介 / 介绍 / 前言 / 预告 / 导学 / 课程说明 / 获取 / 最后 / 结尾 / 致谢
3. 前 60 秒无知识点（抽样确认）

过滤结果必须报告：排除了哪几个、为什么。`--include-intro` 可强制包含。

## 代价评估

```
估算 token ≈ 有效时长(小时) × 1.2 万字 × 1.3
```

超过 5 小时建议分层（先跑 2-3 讲看质量）。

## 两处闸门

| 闸门 | 时机 | 内容 |
|---|---|---|
| 范围确认 | Stage 1 后 | 列出分P 表格，停，等用户选 |
| 代价确认 | Stage 2 后 | 报告 token 估算与耗时，停，等确认 |
